# Flipper-Asset-Packs
Loads of Anims for you to enjoy! Please send me a message or open an issue if you run into any issues with these! 

Shout-out to Atomofiron for the img2fbm tool! It's been loads of help when it comes to making these https://github.com/atomofiron/img2fbm

# How to use (REQUIRES CUSTOM FIRMWARE):

1. Downalod as many of these Asset packs as you'd like
2. Go to your QFlipper app, and navigate to the root directory
3. Navigate to the SD card
5. Most Firmware will provide you with an "asset_packs" folder; navigate to this directory
6. Open a File Explorer or Finder window with the asset pack you'd like to install into your Flipper pulled up
7. Drag and drop the root folder for the pack (ie "C28_Customs_All") to this "asset_packs" folder on your flipper
8. Wait for QFlipper to tell you the upload has completed
9. Disconnect if you'd like (has no effect now that the files are on your Flipper)
10. Navigate to the [Firmware] app for your device. This app is typically near the settings app, and has the firmware's logo + name or abbreviated name (ie "MNTM")
11. Navigate to "Interface"
12. Navigate to "Graphics"
13. "Asset Pack" should now be seen on the top of your screen. Use the left and right D-Pad buttons to find and select your desired asset pack. (To select the asset pack on most firmwares, simply have the text showing, then exit your firmware app)
14. Enjoy your new asset pack!

# C28_Customs [ALL]v5:
A massive pack with all of these animations in one place. This one will take a LONG TIME to load onto your flipper. To load this faster, turn off your flipper, eject the microSD card, insert the microSD card into an adapter for your computer, then load the all pack into the correct folder directly. 
There are some additional anims in this pack from the FZ community, including the following:
1. C28_Vibing_With_Flipper (C28)
2. Assorted CbrPnk2077 Company Logo Anims (Created by Kuronons https://github.com/Kuronons/FZ_graphics)
